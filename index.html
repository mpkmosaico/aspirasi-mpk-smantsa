Cara Export ke Google Sheets

💡 Tips Paling Mudah & 100% Work:

Kamu tidak perlu setup webhook Apps Script yang rumit. Cukup masuk ke Panel Pengurus MPK lalu klik tombol hijau "Export CSV / Google Sheets". File `.csv` akan terunduh. Setelah itu, buka sheets.new, klik menu File → Impor, lalu upload file CSV tersebut. Selesai! Data aspirasi seluruh kelas langsung masuk rapi ke Google Sheet kalian.

Atau jika tetap ingin menggunakan sinkronisasi real-time otomatis via Webhook Apps Script:

  1. Buat Google Sheet baru dengan header kolom: ID | Tanggal | Pilar | Kategori | Kelas | Nama | Judul | Pesan | Status.
  2. Buka menu Ekstensi (Extensions) → Apps Script.
  3. Paste kode script di bawah ini, klik Deploy → New Deployment → Web App (Set akses: Anyone / Siapa saja).
  4. Salin URL Web App yang dihasilkan dan tempel di bawah ini:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.id, data.tanggal, data.pilar, data.subKategori, 
    data.kelas, data.nama, data.judul, data.pesan, data.status
  ]);
  return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
}
